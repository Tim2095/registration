Description
Pikantiko is a full-stack web application built from scratch as part of my portfolio to demonstrate my full-stack development skills. The main goal of this project is to showcase my proficiency in both frontend and backend technologies, rather than focusing on responsive design or aesthetics, which I have demonstrated in other projects. Every line of code in this project was written by me, ensuring a deep understanding of the development process from end to end.

Project Overview
Backend: The backend of Pikantiko is developed using Node.js and Express.js, with MongoDB serving as the database. Mongoose is used as the ODM (Object Data Modeling) library to manage data and interact with the MongoDB database.

Frontend: The frontend is built with React, utilizing modular CSS for component-specific styles, with one component styled using SCSS to demonstrate my knowledge of CSS preprocessors.
